# Event code uses and duplicate event

Spec: `docs/superpowers/specs/2026-10-20-event-code-uses-and-duplicate-design.md`

1. Map redemption rows to name, email, use status, and payment status. Cap at 500.
2. Show those rows when a code row expands on the Codes tab.
3. Duplicate an event as a draft. Copy flows, fields, packages, translations, and emails. Skip attendees and codes.
4. Add the Duplicate button on the event summary. Audit and revalidate.
