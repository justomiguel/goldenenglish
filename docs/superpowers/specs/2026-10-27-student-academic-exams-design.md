# Student academic exams

**Intent:** The academic tab of a student profile lists the cohort exams for that student, including exams that have no published score yet.

**Done when:**
- A student profile shows each exam name, section, date, and state (graded, no score yet, or upcoming).
- A published score appears on the same row.
- An exam with no published grade still appears.
- Other roles do not see the list.
- An empty list shows an empty state.
- The exam name opens the grading page for that exam in the student's section.

**Out of scope:** Learning-route quizzes and rubric charts on this tab.
