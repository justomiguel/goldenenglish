# Admin messages list

**Intent:** The admin messages list shows the messages. It does not show row actions or the bulk action bar.

**Done when:** Each list row is the sender, recipient, preview, and time, and it opens the message. Reply, reply-with-default, read toggle, delete, the selection checkbox, and the bulk bar are absent from the list. Those actions stay on the message detail page. Tests lock the absence of the row actions.

**Out of scope:** The compose button in the page header, the inbox and sent tabs, and the detail-page actions.
