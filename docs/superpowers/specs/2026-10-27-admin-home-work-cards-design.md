# Admin home work cards

**Intent:** The payments, registrations, and messages cards on the admin home use less vertical space. The number and the link stay.

**Done when:** Those three cards use compact padding (`p-3`), a smaller header icon, and a `text-2xl` count. The decorative icon row is gone. The messages preview is one line. The action label sits on the right of the same row as the title, so the wide side of the card is not empty. A test locks the compact classes and that row.

**Out of scope:** Other home cards, card width, and the arrange controls.
