# Student academic tab — latest feedback and grades

## Intent

On an admin student profile, the Academic tab lists the latest teacher feedback and published grades for that student.

## Done when

- A student profile shows up to five recent items, newest first.
- Each item shows the title, the section when known, the teacher when known, the date, the score when published, and the comment when one exists.
- An item with only a score, or only a comment, still appears.
- Draft grades stay hidden.
- A student with no published notes sees an empty state.
- Other roles do not see this list.

## Out of scope

- Editing feedback from this tab.
- Upcoming exams that have no grade and no comment.
- Parent and student portals.
