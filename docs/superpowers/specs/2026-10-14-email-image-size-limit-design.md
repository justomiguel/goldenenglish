# Email image size limit

**Intent:** Raise the email-editor image cap to 10 MB and show that limit in the editor before a file is chosen.

**Done when:** PNG, JPEG, and WebP up to 10 MB upload. A larger file is refused. The editor always shows the 10 MB maximum, and the error repeats it.

**Out of scope:** Other upload limits (logos, landing images, receipts).
