# Centro Listo favicon

## Intent

Give `centrolisto.cl` a favicon set that matches Logo A (sage stroke, terracotta seed, alabaster plate). Use the same mark in the site header and footer.

## Done when

- `public/centrolisto/` has `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png`, `android-chrome-192x192.png`, and `android-chrome-512x512.png`.
- Pulsar platform metadata points at those files.
- The browser theme color on that host is sage `#2D5A47`.
- Header and footer show the mark, not a Lucide icon in a box.

## Out of scope

- Institute tenant favicons (those stay in site setup).
- The generative hero animation.
