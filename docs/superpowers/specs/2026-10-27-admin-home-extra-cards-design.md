# Admin home extra cards

## Intent

The collections, upcoming events, and student pulse cards on the admin home use the same short row as the payments card.

## Done when

- Each of those three cards uses compact padding (`p-3`) and a row with the title and the action on the right.
- The facts sit on one truncated line.
- The events card is one link to the events list. It shows the next event on that line.
- A test locks the compact classes.

## Out of scope

- Shop, changelog, traffic, and shortcut cards.
- The home grid size (small, medium, large).
